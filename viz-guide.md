# Визуализация в Python для EDA

Пример: `src/viz_demo.py`, `src/viz_demo.ipynb`, результаты в `figures/`.

## Кто есть кто

**Matplotlib** - базовый движок. Всё вручную: оси, группы, цвета, легенда. Seaborn построен поверх него.

**Seaborn** - надстройка над matplotlib. Передаёшь DataFrame и имена колонок, группировку (`hue`), легенду и статистику делает сам.

**Plotly** - отдельный движок, рисует в браузере. Синтаксис как у seaborn, но график интерактивный: hover, зум, скрытие групп.

## Что когда

- **Seaborn** - по умолчанию для EDA и итоговых графиков в лабах.
- **Plotly** - когда надо потыкать: найти конкретный выброс, посмотреть поля точки (`hover_data`), позумить.
- **Matplotlib** - редко: нестандартный график или тонкая настройка, очень много точек (plotly тормозит), донастройка seaborn-графика через `ax`.

## Как сохраняется

- **Matplotlib / Seaborn** - `fig.savefig("x.png")` или `"x.pdf"` (вектор). Ничего ставить не надо, в ноутбуке хранятся как картинки и видны везде.
- **Plotly** - `fig.write_html("x.html")`, интерактив сохраняется. Статика (`fig.write_image("x.png")` / `"x.pdf"`) только через отдельный модуль `kaleido` (`pip install kaleido`, нужен Chrome). В `.ipynb` на GitHub и при выгрузке ноутбука в PDF plotly-графики не отображаются.
