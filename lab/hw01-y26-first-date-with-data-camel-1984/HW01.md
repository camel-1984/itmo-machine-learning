### Data

Основные поля: `date`, `admin1`, `admin2`, `market`, `market_id`, `category`, `commodity`, `commodity_id`, `unit`, `pricetype`, `currency`, `price`, `usdprice`.

## 01. Clean Slate

```python
prepare_price_series(prices: np.ndarray) -> tuple[np.ndarray, np.ndarray]
```

Очистите одномерный ряд цен от `NaN`, `±inf` и значений `<= 0`, сохранив порядок. Верните очищенный массив и относительные изменения соседних валидных цен:

$$
r_t = \frac{p_t - p_{t-1}}{p_{t-1}}
$$

Если валидных значений меньше двух, второй массив пустой. Входной массив не изменять. Решение должно быть векторизовано: без `for`, `while` и list comprehensions.

## 02. Spot the Jump

```python
detect_price_jumps(prices: np.ndarray, threshold: float) -> np.ndarray
```

После той же очистки найдите наблюдения, для которых $|r_t| \ge threshold$. Верните **их индексы в исходном массиве** как целочисленный `np.ndarray`.

`threshold < 0` → `ValueError`. Вход не изменять. Решение - без циклов и list comprehensions.

## 03. Reality Check

```python
validate_data(df: pd.DataFrame) -> dict[str, object]
```

Проверьте таблицу, ничего в ней не исправляя. Обязательные колонки:

`date`, `market`, `category`, `commodity`, `unit`, `pricetype`, `currency`, `price`.

Верните словарь **ровно** с ключами:

```python
{
    "missing_columns": ...,
    "duplicate_rows": ...,
    "invalid_prices": ...,
    "missing_markets": ...,
    "invalid_dates": ...,
    "is_valid": ...,
}
```

`missing_columns` - отсортированный список отсутствующих обязательных колонок; `duplicate_rows` - число полных дубликатов после первого. Невалидная цена: пропуск, непреобразуемое в число значение, `±inf` или `<= 0`. Пустой/пробельный `market` считается пропуском. Непреобразуемая или пропущенная дата считается невалидной.

Если соответствующей колонки нет, значение её проверки равно `None`. `is_valid=True` только при полном наборе обязательных колонок и отсутствии перечисленных проблем. Входной `df` не изменять.

## 06. Group Therapy

```python
build_price_report(df: pd.DataFrame, group_by: list[str]) -> pd.DataFrame
```

Допустимые группировки: `admin1`, `admin2`, `market`, `category`, `commodity`, `unit`, `pricetype`. Пустой `group_by`, повторы или неизвестные поля → `ValueError`.

Для каждой группы верните:

`observations`, `markets`, `min_price`, `max_price`, `mean_price`, `median_price`, `price_range`.

`markets` - число уникальных рынков, `price_range = max_price - min_price`. Колонки `group_by` должны идти в переданном порядке, затем метрики в указанном выше порядке. Сортировка: `observations` по убыванию, затем группировочные поля по возрастанию. Индекс сбросить, значения не округлять.
