# ЛР 4. Линейная регрессия: время работы алгоритмов сортировки

## Задача

Вам дан набор запусков нескольких алгоритмов сортировки на массивах с разными
размерами и статистическими характеристиками.

Нужно предсказывать `median_runtime_us` — медианное время работы алгоритма
в микросекундах.

В этой работе недостаточно просто вызвать готовую линейную регрессию.
Вы должны самостоятельно реализовать линейную модель с:

- градиентным спуском;
- L2-регуляризацией;
- обучаемыми весами.

## Данные

`X` содержит:

- `algorithm` — название алгоритма сортировки;
- `n` — размер массива;
- статистические характеристики значений массива:
  `min_value`, `max_value`, `value_range`, `mean_value`, `median_value`,
  `std_value`, `q25`, `q75`, `interquartile_range`, `unique_count`,
  `skewness`, `excess_kurtosis`, `unique_ratio`, `max_frequency_ratio`,
  `normalized_value_entropy`, `mean_absolute_deviation`.

`y` — `pandas.Series` с целевой переменной `median_runtime_us`.

## Обязательная модель

В `model.py` должен быть класс `Model` с интерфейсом:

- `fit(X, y)` — обучение предобработки и модели;
- `predict(X)` — одномерный массив/список вещественных предсказаний;
- `save(path)` — сохранение всего обученного состояния в один файл;
- `Model.load(path)` — загрузка модели из этого файла.

### Требования к реализации линейной регрессии

Коэффициенты линейной модели должны обучаться **вашей реализацией градиентного
спуска**.

Обязательно реализовать L2-регуляризацию.

В этой лабораторной запрщено использовать сторонние библиотеки для реализации линейной регрессии, но разрешено использовать для препроцессинга и обработки данных.

В качестве Loss-функции, которую будет оптимизировать модель, вы можете использовать MSE, MAE, Huber или какую-то другую на ваше усмотрение.

**Запрещено использовать отдельные линейные реализации для каждого алгоритма, у вас должна быть одна линейная модель, которая решает задачу для всех алгоритмов**

## Метрика

Основная метрика — **RMSPE** (Root Mean Squared Percentage Error):

$$
\text{RMSPE} = \sqrt{ \frac{1}{N} \sum_{i=1}^{N} \left( \frac{y_i - \hat{y}_i}{y_i} \right)^2 }
$$

где:

- $N$ — количество объектов;
- $y_i$ — истинное значение времени работы;
- $\hat{y}_i$ — предсказанное значение времени работы.

Чем меньше значение $\text{RMSPE}$, тем лучше.

## Детерминированность

При одинаковых входных данных решение должно давать одинаковый результат.

Если в реализации используется случайность, необходимо явно зафиксировать значение `seed`.
